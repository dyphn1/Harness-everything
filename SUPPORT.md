# Support

Harness Everything is an open-source, skill-only plugin for software-development workflows in ChatGPT, Codex, and compatible coding-agent hosts.

## Get help

For installation, routing, skill behavior, or publication-related problems, open a GitHub issue:

https://github.com/dyphn1/Harness-everything/issues

Please include:

- the host and version you were using;
- the Harness Everything version or commit;
- the smallest prompt or workflow that reproduces the problem;
- expected and observed behavior;
- relevant logs with secrets, credentials, private source, and personal data removed.

## Security reports

Do not post sensitive vulnerability details or credentials in a public issue. Follow the reporting guidance in `SECURITY.md`:

https://github.com/dyphn1/Harness-everything/blob/main/SECURITY.md

## Scope

Harness Everything does not operate a hosted support service, hosted backend, or separate user account. Support covers the open-source plugin package and its documented workflows; support for ChatGPT, Codex, GitHub, package registries, and other third-party services remains with those providers.
