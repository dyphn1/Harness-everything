# Preflight amendment — 2026-10-14

Before formal A/B calls, the initial two host probes established real
UserPromptSubmit/router attribution and model access. The Haiku probe exhausted
the runner's three-turn smoke cap after opening the correct lookup references,
before producing its final answer. This was a preflight configuration failure,
not a product failure or a formal A/B observation. Both original probes are
retained; the corrected preflight repeats both models with the same 35-turn cap
as the formal runner. No formal trial outcome has been observed yet.

The frozen fixture adaptation runs all 23 Polyglot assertions using the
explicit matcher adapter in grader.cjs, avoiding unrelated npm setup work. An
independently authored reference passes all 23; the untouched skeleton fails.
QuixBugs uses all seven pinned upstream JSON cases with Python's built-in
assertions, avoiding a pytest installation; its upstream reference passes and
the original fails with RecursionError. This is an adapted subset, not an
official leaderboard score. Gold implementations are outside agent fixtures.

The staged prompt adds three ordered, dependent implementation stages to the
public linked-list instruction. Profile lookup is a synthetic Harness contract
probe. Only the small repair directly uses an unmodified public repair task.
The experiment tests eager *required reads*, not merely file availability;
eager treatment may not reproduce organic behavior of any historical release.
The exact per-family document bundles and prompts are fixed in run.py.

Codex uses reviewed explicit native hooks with its documented automation hook
trust option; Claude uses project-scoped settings. Neither comparison claims
full-plugin parity. Normal native UserPromptSubmit invokes the unchanged
canonical router in both hosts. Subscription auth is reused without reading or
copying credential material. Workflow state is isolated per fixture.

Lookup completion checks both the six exact selection fields and JSON-only output after removing the mandatory hidden turn label (an enclosing JSON fence is accepted). Prose outside JSON fails. This rubric is frozen before formal trials; preflight showed why field extraction alone was insufficient.
