# Dev / Design Doc Template

Use this shape for a scoped technical decision that doesn't rise to a full ADR (see `grill-with-docs`'s three-criteria test) but is still worth writing down before implementing — the kind of thing a Tier 2 task produces when it makes a real design call along the way.

<spec-template>

## Context

What prompted this decision — the constraint, bug, or request behind it.

## Decision

What was decided, stated plainly.

## Alternatives Considered

Other options that were on the table and why they were passed over.

## Trade-offs

What this decision costs, even though it was the right call.

## Rollout / Rollback

How this ships (flag, gradual, all-at-once) and how to undo it if it's wrong.

</spec-template>
